# Thunderstore release checklist

Run `.\build.ps1 -Package` from the repository root. The generated ZIP contains the DLL, manifest, README, icon, changelog, and license directly at its root.

Before upload, install the ZIP in a new profile and verify crafting, upgrading, building, cooking, fuel, ore, leave-one behavior, restrictions, DadsEPI, and DadsCrafting batch quantities.

Thunderstore versions are immutable. Update the project version, manifest version, plugin constant, and changelog together for every release.

- https://wiki.thunderstore.io/mods/creating-a-package
- https://wiki.thunderstore.io/mods/packaging-your-mods
